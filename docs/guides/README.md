# Guides

| Guide | Helps you |
|---|---|
| [What belongs in a handbook](what-belongs-in-a-handbook.md) | Decide whether something is worth an item, and which kind |
| [Writing a principle](writing-a-principle.md) | Write a value that guides judgment |
| [Writing a working agreement](writing-a-working-agreement.md) | Write how an agent behaves with you |
| [Writing a rule](writing-a-rule.md) | Write a requirement a tool enforces |
| [Writing a guideline](writing-a-guideline.md) | Write a default, with its reason |
| [Writing a procedure](writing-a-procedure.md) | Write the steps of a recurring task |
| [Writing a reference](writing-a-reference.md) | Write facts that are looked up |
| [Writing a decision](writing-a-decision.md) | Record a choice and why it was made |

Each guide shows a worked example of its kind. A template to start from will be printed by
`handbook new <kind>`, generated from the [spec](../../spec/README.md).
