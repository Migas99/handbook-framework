# Error messages say what to do

## Guideline
An error message names what is wrong, where, and what to do next.

## Reason
People and agents act on the message alone, without reading the code that produced it.

## Examples
- `quality/test-value.md: the ID quality.tests-value does not match the path; rename the file or the ID.`
